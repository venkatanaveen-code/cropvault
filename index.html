How to link your Cloud Firestore:

  1. Open your Firebase Console: console.firebase.google.com
  2. Create a project & add a Web App (</>)
  3. Copy your firebaseConfig keys and paste them into firebase-config.js
  4. In Firebase Console, create a Cloud Firestore database and publish rules appropriate for your data.
  5. Save the file and refresh this page. Records will sync in real time!
Security: Firebase web configuration is public; Firestore rules control access. Do not store personal farmer data until access is properly restricted.
